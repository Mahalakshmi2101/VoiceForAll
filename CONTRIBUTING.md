# Contributing to VoiceForAll

Thanks for your interest. Here's how to contribute.

## Easiest contribution — Add a new language

1. Fork this repo
2. Open `gestures.js`
3. Each gesture object has language keys: `en`, `hi`, `ta`, `te`, `ml`, `kn`
4. Add your language code and translation to every gesture object
5. Do the same in the phrase sets in `index.html`
6. Submit a pull request

Language codes to add next: `bn` (Bengali), `or` (Odia), `mr` (Marathi), `pa` (Punjabi)

## Other contributions welcome
- New phrase categories (psychiatry, pediatrics, dental)
- Improved gesture instructions
- Accessibility improvements
- Bug fixes

## Ground rules
- Test on Android Chrome before submitting
- Don't break existing languages
- Keep it offline-first — no new external dependencies
